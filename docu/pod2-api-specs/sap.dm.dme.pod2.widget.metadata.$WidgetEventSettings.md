# $WidgetEventSettings

`sap.dm.dme.pod2.widget.metadata.$WidgetEventSettings`

## Properties

| Name | Type | Optional | Description |
|------|------|----------|-------------|
| `id` | string | No | The ID of the event. Event IDs must be unique within a widget type. |
| `displayName` | string | No | The localized label text. |
| `description` | string | Yes | A localized tooltip explaining the event. If omitted, the displayName will be used as the description. |
