# $CustomInputBaseSettings

`sap.dm.dme.pod2.control.$CustomInputBaseSettings`

## Properties

| Name | Type | Optional | Description |
|------|------|----------|-------------|
| `fontColor` | string | Yes | The color of the text in the input field. |
| `fontSize` | string | Yes | The size of the text in the input field, e.g. "14px", "1rem". |
| `fontWeight` | string | Yes | The weight of the text in the input field, e.g. "normal", "bold", "bolder", "lighter". |
| `fontFamily` | string | Yes | The font family of the text in the input field, e.g. "Arial", "Helvetica". |
