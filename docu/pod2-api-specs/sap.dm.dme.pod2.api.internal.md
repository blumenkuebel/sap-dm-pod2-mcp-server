# internal

`sap.dm.dme.pod2.api.internal`

## Properties

| Name | Type | Optional | Description |
|------|------|----------|-------------|
| `ref` | string | No | The ID of the custom field definition in the format "CustomFieldDefBO: ,,". e.g. "CustomFieldDefBO:1010,ITEM,BULK_MAT_INDICATOR". |
| `plant` | string | No | The plant the custom field is associated with. |
| `tableName` | string | No | The name of the table the custom field is associated with. |
| `fieldName` | string | No | The name of the custom field. |
| `fieldLabel` | string | No | The label for the custom field when displayed to the end user. |
| `sequence` | number | No | The sequence the custom field should be displayed in. |
| `required` | boolean | No | Indicates whether the custom field requires a value. |
| `modifiedDateTime` | string | No | The date and time the custom field definition was last modified in ISO 8601 format. |
| `createdDateTime` | string | No | The date and time the custom field definition was created in ISO 8601 format. |
