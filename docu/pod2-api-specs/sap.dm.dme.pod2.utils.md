# utils

`sap.dm.dme.pod2.utils`

## Properties

| Name | Type | Optional | Description |
|------|------|----------|-------------|
| `code` | string | No | The BCP-47 locale code, dash-delimited (e.g. `en`, `zh-CN`). This is the value sent to the BTP Portal personalization service, which only accepts dash-delimited codes. |
| `nativeName` | string | No | The name of the language as written in itself (locale-neutral). |
