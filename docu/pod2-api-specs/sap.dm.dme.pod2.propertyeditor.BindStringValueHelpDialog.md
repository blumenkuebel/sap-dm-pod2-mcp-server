# BindStringValueHelpDialog

`sap.dm.dme.pod2.propertyeditor.BindStringValueHelpDialog`

Dialog that allows the user build a binding expression that can contain text interspersed with binding
expressions and see a preview of the resolved value.

## Constructor

```
new BindStringValueHelpDialog (sInitialValue, mSettingsopt)
```

**Parameters:**

| Name | Type | Optional | Description |
|------|------|----------|-------------|
| `sInitialValue` | string | No | The initial value to show in the dialog. |
| `hideInsertDataButton` | boolean | Yes | If true, the "Insert Data" button will be hidden. |
| `hideInsertTextButton` | boolean | Yes | If true, the "Insert Text" button will be hidden. |
| `hideInsertExpressionButton` | boolean | Yes | If true, the "Insert Expression" button will be hidden. |
