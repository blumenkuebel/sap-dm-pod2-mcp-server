# WidgetEvent

`sap.dm.dme.pod2.widget.metadata.WidgetEvent`

Represents metadata about an event that a widget can fire. This is typically triggered by some user interaction
like pressing a button or selecting a row from a table.

## Constructor

```
new WidgetEvent (mSettings)
```

**Parameters:**

| Name | Type | Optional | Description |
|------|------|----------|-------------|
| `mSettings` | sap.dm.dme.pod2.widget.metadata.$WidgetEventSettings | No | The settings for the event. |

## Methods

### getDescription () → {string}

Gets the description of the event.

**Returns:** string - string

### getDisplayName () → {string}

Gets the display name of the event.

**Returns:** string - string

### getId () → {string}

Gets the ID of the event.

**Returns:** string - string
