# datafields

`sap.dm.dme.pod2.api.datafields`

## Properties

| Name | Type | Optional | Description |
|------|------|----------|-------------|
| `fieldValue` | string | No | The value of the option. It must be unique within the data field options list. |
| `optionLabel` | string | No | The label for the option. If not provided, the fieldValue will be used as the label. |
| `isDefault` | boolean | No | Indicates if this option is the default. There can be only one default option in the data field options list. |
